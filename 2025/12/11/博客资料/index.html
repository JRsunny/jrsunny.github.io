一、图片与素材

Pixabay

全球最大的图片分享网站之一，拥有超过 550 万张优质图片和视频素材，涵盖图片、插画、向量图、视频、音乐、音效和 GIF 素材等，全部免费且可商用，支持中文搜索。

  • 地址：pixabay.com

同类免版税图库还有 Unsplash、Pexels、Piqsels、StockSnap、Simple Desktops、故宫壁纸、ESO Images 等，按“技术文用极简、随笔用风景”来挑。

1. DavidChan’s Blog：把 SEO 和广告当工程做

  • 站点：imchenway.com
  • 原文：Hexo SEO 与 AdSense 优化实录

一篇很完整的“Hexo 站点可见性”实录。可抄的点：

  • 配置一致性：url、canonical、robots、sitemap 必须指向同一个域名，缺一处就漏权重；
  • robots.txt 显式指 sitemap，比等搜索引擎自己发现快；
  • OG / Twitter Card / <html lang> 由模板生成，中文页别标成英文；
  • 性能：懒加载 + CSS/JS/HTML 压缩 + 脚本 defer，首屏轻了广告才更容易曝光；
  • 广告：头部只加载一次 adsbygoogle.js，文章内再 push 一个手动位，与自动广告并存；
  • 闭环：Search Console 看哪些词有曝光，反推下一篇写什么。

2. ZhiYuan 的博客：Butterfly 主题升级的写法

  • 站点：1zzhiyuan.github.io
  • 原文：博客全新升级 — Butterfly 主题焕新

把“换主题”写成一篇功能清单，读者一眼知道升级了什么：

  • 暗色模式（跟随系统 + 手动切换）、站内搜索、代码高亮与复制、右侧目录、图片灯箱、giscus 评论；
  • 每个特性配一条配置片段（darkmode.autoChangeMode、local_search.preload、canvas_nest），照着能改；
  • 结尾落到互动：“欢迎在评论区说说你的看法”。

值得学的是结构：不是罗列“我改了配置”，而是“你会得到什么 → 怎么配”。

3. Martin’s Blog：博客 2.0 迁移与自动化

  • 站点：blog.bruxelles-ai.ac.cn
  • 原文：博客 2.0 正式上线｜Martin 的小站焕新记

一次完整的“从 1.0 到 2.0”复盘，重点在工程化：

  • 部署：GitHub 托管 + Cloudflare Pages 自动构建，推送即上线；
  • 图床：老图迁到 PicGo，加载和维护都变轻；
  • 自动化：用规则做文章自动分类，用 MCP 自动配图；
  • 小惊喜：自定义 JS 让每次构建自动换导航封面，成本低但“看起来一直在更新”。

4. 林中Yi轩：134 篇的长期主义

  • 站点：gwacoe.com
  • 分类页示例：单片机

不是“教程文”，而是长期维护的样本：

  • 分类骨架稳：Linux 24 篇、Linux 命令 8 篇、单片机、Git、Android……一级分类少，标签细；
  • 标题即索引：统一 分类--主题 格式（如「单片机–51单片机存储器访问」），归档页像目录；
  • 站点是立体的：正文之外还有电影、书单、音乐子站、说说、留言板、友链；
  • 自建统计：busuanzi 慢，就换成自建 Vercount；
  • 独立域名 + 备案，国内访问稳定。

四、从这 4 个站提炼的 6 条

  1. 先一致，再优化：域名、canonical、sitemap、robots 指向同一个地方，比装十个插件有用。
  2. 可被发现：sitemap 自动生成只是第一步，Search Console 提交与“请求编入索引”才是闭环。
  3. 性能是运营成本：图片本地化 + 压缩 + 懒加载，直接影响跳出率与广告曝光。
  4. 分类稳、标签细、标题有格式：三个月后自己回来看得懂，读者才可能顺着读第二篇。
  5. 升级本身值得写：换主题、迁移、加功能，写成“你会得到什么 + 怎么配”，比纯技术日志有人看。
  6. 自动化要从第一天做：部署、图床、分类，哪一步还在手动，哪一步就会成为停止更新的理由。
