避免递归循环问题所需的数据

发表于2024-05-14|更新于2026-10-09|freqtrade教学策略技巧与代码片段
|阅读量:

原文标题：Data required to avoid recursive loop issue
原文链接：https://botacademy.ddns.net/2024/05/14/data-required-to-avoid-recursive-loop-issue/
发布日期：2024-05-14

以下是避免recursive loop issue所需的数据倍数。例如，EMA 需要 3 倍数据，也就是说，要计算长度为 200 的 EMA，至少需要 600 行数据。

注意：以下列表会在需要时更新

无法避免的 lookahead bias

  • qtpylib.cci
  • qtpylib.vwap

无法避免的 recursive loop issue

  • ta.AD
  • ta.OBV
  • qtpylib.pvt
  • pandas_ta.ebsw（无法在 recursive test 中运行）

通用经验法则

3 倍

  • ta.EMA
  • ta.DEMA
  • ta.BBANDS 使用 matype = 1 (EMA)
  • ta.BBANDS 使用 matype = 3 (DEMA)
  • smi_momentum (nilux)

4 倍

  • qtpylib.rolling_weighted_mean
  • qtpylib.hull_moving_average
  • qtpylib.hma

5 倍

  • ta.KAMA
  • ta.TEMA
  • ta.BBANDS 使用 matype = 4 (TEMA)
  • ta.BBANDS 使用 matype = 6 (KAMA)
  • ta.ADOSC
  • ta.MACDEXT 基于 slowperiod，当 slowmatype = 2 (WMA)
  • ta.MACDEXT 基于 slowperiod，当 slowmatype = 5 (TRIMA)

6 倍

  • ta.MACDFIX
  • ta.TRIX
  • 使用 EMA 的 Elliot Wave Oscillator

7 倍

  • ta.T3
  • ta.APO 使用 matype = 1 (EMA)
  • ta.PPO 基于 slowperiod，当 matype = 1 (EMA)
  • ta.PPO 基于 slowperiod，当 matype = 6 (KAMA)
  • pandas_ta.apo 使用 matype=”ema”
  • pandas_ta.bias 使用 matype=”ema”

8 倍

  • ta.MINUS_DI
  • ta.MINUS_DM
  • ta.PLUS_DI
  • ta.PLUS_DM
  • ta.RSI
  • ta.ATR
  • ta.NATR
  • ta.APO 使用 matype = 3 (DEMA)
  • ta.APO 使用 matype = 4 (TEMA)
  • ta.MACD 基于 slowperiod，当 fastperiod < slowperiod
  • ta.MACDEXT 基于 slowperiod，当 slowmatype = 1 (EMA)
  • ta.MACDEXT 基于 slowperiod，当 slowmatype = 3 (DEMA)
  • ta.PPO 基于 slowperiod，当 matype = 3 (DEMA)

9 倍

  • ta.STOCHRSI
  • pta.cmo
  • ta.MACDEXT 基于 slowperiod，当 slowmatype = 4 (TEMA)
  • ta.PPO 基于 slowperiod，当 matype = 4 (TEMA)

10 倍

  • ta.APO 使用 matype = 6 (KAMA)
  • ta.MACDEXT 基于 fastperiod，当 fastmatype = 1 (EMA) 且 slowmatype = 0、signalmatype = 0

11 倍

  • ta.MACDEXT 基于 slowperiod，当 slowmatype = 6 (KAMA)

12 倍

  • ta.DX

13 倍

  • ta.ADX
  • ta.ADXR
  • ta.CMO

16 倍

  • ta.MACD[‘macd’] 基于 fastperiod

需逐案分析的指标

这一类指标必须使用 recursive-analysis 手动检查，以确保你的 startup_candle_count 足够。

pta.kama

该指标有 length、fast 和 slow 变量，它们会影响所需的 startup candle。我无法给出通用公式。目前我发现的是，对于 startup_candle_count 为 999 的情况，你可以使用的最大 length 是 200，并使用默认的 fast 和 slow

ta.STOCHF
  • matype=0 (SMA)
    (fastk_period + fastd_period) <= startup_candle_count
  • matype=1 (EMA)
  • matype=2 (WMA)
  • matype=3 (DEMA)
  • matype=4 (TEMA)
  • matype=5 (TRIMA)
  • matype=6 (KAMA)
  • matype=7 (MAMA)
  • matype=8 (T3)
