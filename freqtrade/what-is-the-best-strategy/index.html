什么是最好的策略？

发表于2023-07-09|更新于2026-10-09|freqtrade教学问答与概念
|阅读量:

原文标题：What is the best strategy?
原文链接：https://botacademy.ddns.net/2023/07/09/what-is-the-best-strategy/
发布日期：2023-07-09

这通常是许多从未接触过算法交易（甚至手动交易）的新用户提出的第一个问题。遗憾的是，没有哪一种 strategy 可以被客观地视为最好的。每种 strategy 都有其优缺点，结果也会因交易所、stake 币种以及市场类型（现货或合约）的不同而有所差异。

此外，对于什么定义了“最好”的 strategy，人们并没有共识。一个理想的“最好” strategy 应该包含大量的交易次数、较高的平均利润百分比、较高的胜率、较低的回撤，并且无论市场状况如何都能稳定交易。然而，这种完美无瑕的 strategy 并不公开存在。相反，你需要根据自己的具体交易和风险管理偏好做出取舍。根据我的经验，你可以在 strategy 中优先实现这些理想要素中的两个。选择与你的目标相符的组合。

我强烈建议你投入大量精力去寻找“最好”的 strategy，因为这涉及你自己辛苦赚来的钱。它不是我的，也不属于你在网上遇到的陌生人——它是你的。你可以在 GitHub 仓库和 Freqtrade Discord 服务器上找到大量的 strategy。对它们进行严格的 backtest，找出那些能产生良好结果的，并进行长时间的 dry run，以观察实时表现并将其与 backtest 结果进行比较。如果 dry run 结果与 backtest 结果之间存在显著差异，这可能表明该 strategy 人为地优化了 backtest 表现。

只有当你对自己的 strategy 有信心时，才应该用少量资金开始实盘交易（请查看你偏好的交易所允许的最低 stake 金额，因为各交易所不同）。重要的是要记住，过去并不总能预示未来，尽管有些人可能不这么认为。始终控制风险。

为了长期成功，定期评估和调整你的 strategy 也很重要。过去有效的方法现在可能不再成功，尤其是在动荡的加密货币市场中。继续尝试各种概念和方法，看看什么能帮助你完善你的 strategy。

请记住，成功需要投入、持续学习和适应。这不是一段简单或短暂的旅程。要保持坚持、耐心，并随着你对市场的了解和经验的积累，愿意调整你的 strategy。保持开放的心态，大量阅读，并尝试各种方法来确定最适合你的方式。通过这种持续学习和实验的过程，你可以逐步创建和改进你的交易 strategy。

在你旅程中能提供帮助的少数资源

  • froggleston 的 freqtrade jupyter notebook，它有几个很酷的功能，其中之一是详细比较 backtest 结果与 dry/live 结果
  • frequenthippo 网站，其中有大量来自公开 strategy 的长期 dry run 和 backtest
