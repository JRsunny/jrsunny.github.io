发布日期：2023-09-17

除非你所有的 bot 都跑在同一台本地电脑上，否则在所有 VPS/电脑上安装 Tailscale是必须的。在所有机器上装好 Tailscale 之后，把它们合并到一个 frequi 里的步骤就很简单了。首先，选一个 bot 作为主 frequi。记下它的 Tailscale IP 和端口号。本教程里，假设 Tailscale IP 是 123.456.543.212，端口是 7654。

对于每一个你想加进主 frequi 的其他 bot，在它们 config.json 的 CORS_origin 部分，加上主 bot 的 IP 和端口。以本例来说：

注意我在 CORS_origins 末尾没有加 /。大多数时候，用户会犯这个错，在末尾加上它。CORS 相当挑剔，它要求地址和你浏览器里访问主 frequi 时输入的地址完全一致。

你要做的就这些。在所有其他 bot 上加上那个 CORS_origins，现在你就可以从主 frequi 里添加这些 bot 了。

作为替代方案，还有几个非官方项目也在做类似的事情（把多个 bot 合并到一个视图里的 dashboard）：

  • https://github.com/stash86/ft-dashboard（一个只读的 web dashboard）
  • https://github.com/froggleston/freqtrade-frogtrade9000（命令行 dashboard）
