Freqtrade如何应用杠杆

发表于2025-10-23|更新于2026-10-09|freqtrade教学问答与概念
|阅读量:

原文标题：How Freqtrade applies leverage
原文链接：https://botacademy.ddns.net/2025/10/23/how-freqtrade-applies-leverage/
发布日期：2025-10-23

先声明一下，我从不在外汇或股票交易中使用杠杆，所以加密货币是我第一次用杠杆交易。显然，根据一些用户的说法，加密货币交易所应用杠杆的方式与外汇/股票有所不同，这导致了一些困惑。这篇文章旨在澄清这个问题。好，我们开始吧。看看这笔杠杆交易。

我会逐步解释那里的所有数字。首先，使用的 stake 金额是 1661.884。开仓率是 0.0854。所以在杠杆之前，你应该只收到 1661.884 / 0.0854 的金额，即 19.460。由于我们使用了 3 倍杠杆，你得到的金额是 19.460 * 3，即 58.380。

接下来，我们来看看利润数字是如何匹配的。开仓率是 0.0854，平仓率是 0.0866。百分比变化是 (0.0866 – 0.0854) * 100 / 0.0854 = 1.4%。Binance 上 maker 的手续费是 0.05%，所以如果我们把手续费算进去，杠杆前的实际利润百分比是 1.4 – (2 * 0.05) = 1.3%。由于我们使用了 3 倍杠杆，我们得到的利润是 1.3 * 3 = 3.9%。我们得到的绝对利润是 0.039 * 1661.884 = 64.813476 USDT，这与上面的数字相似。差异来自实际应用的手续费，因为我们在上面的计算中使用了统一费率。

如你所见，所有数字都匹配，除了绝对利润上的微小差异，因为交易所不把手续费计入其利润计算中。希望这能澄清任何困惑。如果你不相信上面的步骤，可以在加密货币交易所手动交易，例如 Binance，然后使用上面的步骤。你会看到它将会匹配。
