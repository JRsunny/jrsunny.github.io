干跑和实盘运行的区别

发表于2026-02-12|更新于2026-10-09|freqtrade教学心得与认知
|阅读量:

原文标题：Difference between dry and live run
原文链接：https://botacademy.ddns.net/2026/02/12/difference-between-dry-and-live-run/
发布日期：2026-02-12

虽然 dry run 会尽可能模拟实盘运行，但仍然会有一些差异，这些差异可能会也可能不会影响你的交易结果。

你不会经历下单带来的滑点

假设你想用市价单买入 100 个币 A。机器人会从交易所拉取最新的订单簿数据，与你的目标订单进行比对。好，它发现有一笔 200 个币、价格 $0.51 的卖单挂着。在 dry run 中，机器人会立即把这笔订单标记为成功。你以 $0.51 的价格买入了 100 个币 A。

在实盘中，情况就不一样了。机器人必须把订单发送到交易所。从上次拉取订单簿到当前订单簿之间，已经过去了一些时间（哪怕很短）。价格可能已经变了，可能跌了也可能涨了。你的订单最终可能以 $0.53 成交 100 个币 A，也可能以 $0.48 成交。

同样的事情也会发生在任何加仓、部分止盈和/或全部平仓的订单上。如果你把所有差异加起来，可能很显著，也可能不显著。

你不会受到其他速率限制的约束

在 dry run 中，你唯一需要担心的就是 K 线拉取的速率限制。但在实盘交易中，一些交易所对某些特殊情况有额外的速率限制或交易限制。我过去就遇到过一些，比如

或者其他限制，比如因为你在单台 VPS 上跑了太多频繁交易的实盘机器人，导致你被限速。这些限制不会在你的 dry run 中出现。

你不会影响价格

如果你使用市价单交易，并且要么使用大额 stake，要么交易流动性低的币，这一点尤其重要。假设你想买入 100 个币 A。当机器人拉取订单簿时，它发现了这些卖单

你的 dry run 入场订单最终结果是：你以 $0.53 的平均入场价买入了 100 个币 A。但如果你去看 K 线图，币 A 的最新价格仍然停留在 $0.50，而如果是实盘交易，最新价格本应是 $0.55。

你对市场来说是无敌的

接着上一点说，值得注意的是，市场中的其他（机器人）交易者会对不同的市场变化做出不同的反应。从上面的例子来看，当币 A 的价格停留在 $0.50，或者因为有人刚买了 100 个而涨到 $0.55 时，市场的反应是不同的。

假设有一个交易者，一旦价格触及 $0.55 就会挂出卖单。在你的 dry run 情况下，那笔卖单永远不会出现，因为（比如说）接下来 2 天实盘价格都没到那个位置。但在实盘交易中情况就不同了，在你完成入场订单后，交易者 B 的卖单立刻挂出，把价格压到（比如）$0.45。这可能触发交易者 C 的动作，进而触发交易者 D 的动作，如此连锁下去。

在某些情况下，仅仅因为你在订单簿上挂了一笔真实的限价单，就可能触发其他人的动作，而这在 dry run 中是不会发生的。

以后我想起来的时候可能会补充更多点，但目前这些点已经足以说明在 dry run 和实盘上运行策略之间的差异了
