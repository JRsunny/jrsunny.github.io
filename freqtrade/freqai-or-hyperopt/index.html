Freqai 还是 hyperopt？

发表于2025-04-02|更新于2026-10-09|freqtrade教学问答与概念
|阅读量:

原文标题：Freqai or hyperopt?
原文链接：https://botacademy.ddns.net/2025/04/02/freqai-or-hyperopt/
发布日期：2025-04-02

我该用哪个？FreqAI 还是 hyperopt，还是两个都用？FreqAI 比 hyperopt 更好吗？

上面这些是新用户经常问的问题。答案很简单：哪个能改进你的 strategy，就用哪个。两者做的事情不同，也能以不同的方式改进你的 strategy。让我简单解释一下它们各自到底在做什么。

Hyperopt

Hyperopt 只是一系列 backtest，用来找出能产生最低 loss 值的参数。它使用历史数据来找出这些参数。过去表现良好的参数并不能保证未来依然表现良好。Hyperopt 无法预测未来，因为它不涉及任何机器学习。

Freqtrade 不会自动运行 hyperopt 流程。所以如果你想在未来更新参数，要么手动运行 hyperopt 流程，要么写个脚本按指定间隔自动运行。

Hyperopt 的一个例子是：你想找出哪个 EMA 适合你的 dataframe["close"] < dataframe["EMA_x"] 逻辑。根据你指定的 loss 函数，假设 hyperopt 发现 EMA_100 是最佳参数。它未来还会表现良好吗？没人知道。

FreqAI

为简单起见，本文中我将描述 regressor/classifier 模型的作用。简单来说，它们做的事情是接收定义好的 features（基于过去数据），并用这些数据来预测指定的（未来）targets。FreqAI 不知道（也不关心）strategy 是否盈利。它只关心能否产生好的预测。你的责任是知道如何利用这些 targets 来创建盈利的 strategy。

举个例子，让我们拿这个官方示例 strategy 来说。模型会使用定义好的 features（rsi、mfi、hour 等）来预测 target dataframe["&-s_close"]，也就是预测未来 label_period_candles 根 K 线价格的平均走势。如何使用这个预测取决于你的创造力。示例中使用的逻辑可能盈利，也可能不盈利。但如上所述，这并不是 FreqAI 关注的重点。

使用 FreqAI 的优势在于它会按定义的频率重新训练，这意味着它会通过重新计算 targets 来自动适应市场。FreqAI 的劣势在于，正如我上面多次重复的，即使它能准确预测 targets，也无法保证这会让你的 strategy 盈利。甚至连过去盈利的保证都没有，而 hyperopt 至少还能提供这一点（并不是说过去盈利就能保证未来盈利）。

那么哪个更好？

两者都不比另一个更好。它们做的事情不同，关注的方向也不同。就我个人而言，我在自己的一些 strategy 上两个都用。你只需要理解它们各自提供什么，以及如何正确利用它们。根据我的经验，FreqAI 可能比 hyperopt 需要更多时间来学习，因为你需要大量试错才能找到 features 和 targets 的良好组合。你不会想要太多 features，否则训练模型会花上很久。有些 features 可能不是好的 features，或者与现有的相似 features 冗余。
